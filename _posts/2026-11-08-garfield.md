## Getting L.Wilson Via LogonScripts

Interesting to note that we have `WRITE scriptPath` on `Liz Wilson` and `Liz Wilson ADM` due to being in the `IT Support` group. `scriptPath` is the attribute that determines what `login scripts` that a user will execute upon an `interactive logon`. These scripts are usually stored in `SMB` either on `SYSVOL` or the `NETLOGON` shares. Let's take a look.

Both the `SYSVOL` and `NETLOGON` shares are `Distributed File System Shares`, which means that they'll automatically try to connect the client (us) to the nearest `DC` which could either be `DC01` or `RODC01`. If we attempt to connect to `NETLOGON` we can see that `RODC01` has registered itself as the `DFS` target for the share as we do not have the `RODC` in our `/etc/hosts` file yet.

```bash
$ smbclient -U 'j.arbuckle%Th1sD4mnC4t!@1978' //garfield.htb/NETLOGON      
do_connect: Connection to RODC01.garfield.htb failed (Error NT_STATUS_UNSUCCESSFUL)

```
{:.filename="RODC Connection Failure"}

If we keep connecting we should be able to reach the `fallback` server, which should be `DC01`, this is what we want since we can't be sure that the `RODC` can connect back to us as it's in the `192.168.100.0` network.

